# 🎓 CampusCook AI : L'assistant alimentaire intelligent pour étudiants

Bienvenue dans le dépôt de **CampusCook AI**, une application propulsée par l'Intelligence Artificielle et conçue spécifiquement pour répondre aux contraintes alimentaires, budgétaires et matérielles des étudiants.

Ce projet a été réalisé dans le cadre du cours *Advanced AI Algorithms (AAA)*.

---

## 🚀 Démarrage rapide (Reproductibilité)

L'application est conçue pour être facilement testable. Suivez ces étapes pour lancer la démonstration sur votre machine :

1. **Ouvrez un terminal** (ou invite de commande) à la racine du dossier du projet.
2. **Exécutez la commande suivante** pour lancer l'interface web :
   ```bash
   python-3.14.10-embed-amd64\python.exe -m streamlit run app.py
